## Что делает приложение

- Открывает вашего существующего агента в браузере телефона и устанавливается как PWA.
- Передаёт текст в тот же серверный агент и читает его общую историю.
- Добавляет голосовой маршрут: запись → распознавание → ваш агент → озвучка ответа.
- Сохраняет одну серверную историю между Telegram и приложением при подключении соответствующего адаптера.
- Даёт примеры входа владельца, HTTPS, ограничения запросов и резервного копирования.

Телефон → защищённый шлюз приложения → ваш существующий агент → его история и память.

Это самостоятельный веб-вход к вашему агенту. Доступность определяется вашей сетью, доменом, сервером и выбранными сервисами; проект не содержит VPN или средств обхода блокировок.

## Для кого

Для владельцев уже работающего Telegram-агента, которым нужен дополнительный вход с телефона. Нужен доступ к серверному коду агента или его API. Пошагово начинаем с [того, что уже должно быть готово](route/01_PREREQUISITES.md).

Сам агент, его модель и память остаются в вашем существующем runtime. Код подключения расположен в `connector/`. Для runtime без HTTP есть [пример локального адаптера](connector/tg_runtime_bridge.py).

## Начать

1. Скачайте проект: **Code → Download ZIP**, распакуйте архив.
2. Откройте [00_START_HERE.md](00_START_HERE.md) и пройдите шесть этапов.
3. Подключите API или функцию своего агента по [контракту адаптера](route/02_CONNECTOR.md).
4. Настройте домен, HTTPS и вход владельца; затем проверьте текстовый разговор и общую историю.
5. Подключите выбранные сервисы распознавания и озвучки по [инструкции для голоса](route/05_VOICE_CONTINUITY.md).

Сервер, домен и API провайдеров оплачиваются в ваших аккаунтах. Код и инструкции бесплатны. Голосовые API по умолчанию выключены; включайте их после настройки своих лимитов.

## Проверить код локально

Python 3.10+, без внешних Python-зависимостей:

```sh
python3 -m unittest discover -s tests -p test_connector.py -v
```

Тесты используют искусственный агент и имитацию речи; платных API-вызовов в них нет. Они проверяют вход, привязку владельца и разговора, общую историю, отмену, повторы, сроки ожидания, аудио и восстановление.

## Статус первой версии

**Учебная версия для разработчиков.** Подготовлены исходники и маршрут подключения; проведены проверки на синтетическом runtime и в Chromium с синтетическим микрофоном. Реальный адаптер вашего агента, речь провайдера, установка на iPhone/Android и развёртывание проверяются в вашей конфигурации. Полный список: [CHECKS.md](CHECKS.md).

Реальный разговор Светланы с Виком в фильме показывает её собственное установленное приложение. Учебный комплект требует подключения к вашему runtime и не является готовой копией её личного агента.
