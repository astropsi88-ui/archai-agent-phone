# Граница
Connector только передаёт реплики существующему агенту и читает разрешённую историю. Личность, модель, память, инструменты и рабочие права определяет existing runtime. Нет shell endpoint, загрузки произвольных файлов, API keys в браузере или автоматического Telegram polling. Private данные другой системы в комплект не входят.
